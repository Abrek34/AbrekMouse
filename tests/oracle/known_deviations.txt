# T13 — Known, intentional deviations of the local port from the official
# RawAccel reference. Rows here are expected to differ; run_oracle.sh treats
# only rows NOT in this list as drift. Format: <case-name>\t<spd>
#
# Deviation classes (both are documented port conventions with their own tests):
#  1. classic *exp<=1* → the local port's "linear path" returns the constant
#     gain 1+acceleration. The official reference keeps x^(exp-1), which
#     explodes (e.g. gain ≈ 448 at speed 0.001 for exp=0.5) on the physical
#     expectation that exp<1 is an unusual config. AGENTS.md test:
#     "classic linear path (exp<=1) cap".
#     Reachability (T15/T16): the GUI spinner is bounded to [1,10]
#     (gui/ui_builder.inl `make_spin(1,10,...)`), and `sanitize_accel_args`
#     now clamps exponent_classic to [1,10] (src/config.cpp), so a real
#     daemon/GUI/CLI config can never carry exp<1 — these rows are only
#     reachable through the raw algorithm API, where the port keeps its
#     safe documented behavior.
#  2. power / synchronous at speed 0 → the port guards `x <= 0 → 1.0`
#     (identity); the reference blindly runs the formula, yielding artifacts
#     (power → 0, synchronous → ≈0.667). Speed 0 is non-physical for a mouse
#     (output = input × gain = 0 anyway). AGENTS.md test: "synchronous power<1".
